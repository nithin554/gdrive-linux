3. Description of Service

gdrive-linux is a desktop application that:

  • Authenticates with your Google account via OAuth 2.0
  • Mounts your Google Drive as a FUSE virtual filesystem at ~/Google Drive (<email>)
  • Streams file content directly from Google Drive on read, uploading changes on close
  • Provides a system tray interface for account management, settings, and application control

The Software is provided "as is" and the developers make no guarantees about its availability, reliability, or fitness for any particular purpose.
