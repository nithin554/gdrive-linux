This Privacy Policy explains how gdrive-linux ("the application", "we", "our") handles your data. gdrive-linux is an open-source desktop application that mounts your Google Drive as a FUSE virtual filesystem on Linux. It is distributed under the MIT License and the full source code is publicly available on GitHub.

Short version: gdrive-linux collects no data, sends no telemetry, displays no ads, and communicates exclusively with Google's servers. File content is streamed directly from Google Drive into memory and is never stored on disk.

1. Information We Access

1.1 Google Account Data (via OAuth 2.0)

When you authenticate, gdrive-linux requests the following OAuth scopes:

  • https://www.googleapis.com/auth/drive.readonly — Read access to file metadata and content. Used exclusively to list your files and stream their content when opened.
  • https://www.googleapis.com/auth/drive.file — Per-file read/write access to files you create or open through the application. Used to save changes you make to files.
  • https://www.googleapis.com/auth/userinfo.email — Read-only access to your email address. Used solely to label the mount point path (e.g., ~/Google Drive (user@gmail.com)) and display your account email in the system tray menu.

1.2 Local Configuration Data

The following files are created locally in ~/.config/gdrive-linux/:

  • token.json — Your Google OAuth credentials (access token, refresh token). Stored with file permissions 600 (owner read/write only).
  • sync_mapping.json — A local index of Drive file IDs mapped to paths, used for fast metadata lookups.
  • settings.json — Application preferences such as autostart toggle.

A cache directory at ~/.cache/gdrive-linux/cache/ may store recently accessed file chunks for performance, managed with automatic LRU eviction. This cache is local-only and never transmitted anywhere.

2. How We Use Your Data

  • File metadata and content are accessed only to present your Google Drive as a mounted filesystem and allow read/write operations. Metadata is cached locally for performance; file content is streamed into memory on demand and never written to disk.
  • Your email address is used only for display purposes (mount point path and tray menu). It is not stored, logged, or transmitted anywhere except to Google's API during authentication.
  • No other use. We do not access, process, or store your data for any other purpose.

3. Data Sharing & Third Parties

  • No data is shared with third parties. gdrive-linux communicates exclusively with Google's APIs at www.googleapis.com and oauth2.googleapis.com.
  • No telemetry, analytics, or crash reporting. The application contains no tracking code, no analytics SDKs, and no telemetry of any kind.
  • No ads. gdrive-linux does not display or serve advertisements.
  • No external servers. Aside from Google's own API endpoints, gdrive-linux does not contact any other server or service.

4. Data Storage & Security

  • Token storage. Your OAuth token is stored in ~/.config/gdrive-linux/token.json with restricted permissions. It is never shared or transmitted except to Google's token endpoint for authentication and token refresh.
  • No cloud sync of config. Local configuration files are never synced, backed up, or transmitted.
  • File content is ephemeral. When you read a file, its content is streamed into memory and discarded when no longer needed. Nothing is permanently stored on disk.

5. Data Deletion & Revocation

You have full control over your data:

  • Revoke Google access at any time from your Google Account Permissions page.
  • Reset All Data via the application's tray menu → Settings → Reset All Data. This deletes your local token, cache, and sync mapping, logging you out.
  • Manual deletion: Delete the ~/.config/gdrive-linux/ and ~/.cache/gdrive-linux/ directories to remove all locally stored data.

6. Children's Privacy

gdrive-linux is not directed at children under the age of 13. We do not knowingly collect personal information from children.

7. Open Source & Audibility

The entire source code of gdrive-linux is publicly available under the MIT License at github.com/nithin554/gdrive-linux. Anyone can inspect, build, and verify what the application does.

8. Changes to This Policy

If this Privacy Policy is updated, the "Last updated" date at the top of this page will be revised. Significant changes will be communicated via the project's release notes.
